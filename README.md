## Overview

This project is a simple browser-based task list. Users can add tasks and view them in a focused interface. It is designed to practise DOM interaction and the fundamentals of front-end development.

## Features

- Add tasks to a list
- View tasks in the browser
- Simple interface with no build tools
- Runs locally without a server

## Technology stack

- **HTML** for structure
- **CSS** for styling
- **JavaScript** for task input and page interaction

## Run locally

```bash
git clone https://github.com/rlaharira/todo-list.git
cd todo-list
```

Open `index.html` in your browser.
