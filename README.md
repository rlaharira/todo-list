# To-Do List

A lightweight browser-based task list built with **HTML, CSS, and JavaScript**.

## Features

- Add tasks to a list
- Simple, focused user interface
- Runs directly in a web browser

## Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/rlaharira/todo-list.git
   cd todo-list
   ```

2. Open `index.html` in your browser.

No build tools or package installation are required.

## Built with

- HTML
- CSS
- JavaScript
